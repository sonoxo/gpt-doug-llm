# NXYZ Mouse Mic — Icon Set

These PNG files are the production icon set referenced by `../manifest.json`.

| Asset | Size | Use |
| --- | ---: | --- |
| `icon16.png` | 16×16 px | Small Chrome UI / toolbar context |
| `icon48.png` | 48×48 px | Extension management surfaces |
| `icon128.png` | 128×128 px | Primary extension icon and Chrome Web Store icon source |

## Brand treatment

The current mark uses the NXYZ `N` accent with a white microphone glyph on the purple rounded-square application tile.

![NXYZ Mouse Mic icon](./icon128.png)

## Shipping rule

Do not rename or remove these files without updating both `../manifest.json` icon maps. The 128×128 PNG should also be used as the primary Chrome Web Store icon unless a later approved brand asset supersedes it.
