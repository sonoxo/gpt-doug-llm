# ZYRA Intelligence Contingency Plan

## Command objective
Restore a known-good intelligence capability while preserving provenance, integrity, and security evidence.

## Recovery priority
1. Repository integrity and trusted commit state.
2. Security/CI gates and dependency integrity.
3. Virginia Intelligence Command policy and gate.
4. QTFY MASTER LOCK and Glass Onion lock verification.
5. Local model/runtime availability.
6. Live intelligence feed synchronization.

## Recovery procedure
- Stop affected runtime services.
- Preserve audit and incident evidence.
- Restore code/configuration from a verified commit or approved backup.
- Restore intelligence data only from hash-verified artifacts.
- Run security gate, regression suite, ontology locks, and government-intelligence audit.
- Re-enable functions in dependency order.
- Record recovery time, data loss if any, deviations, and POA&M actions.

## Deployment evidence required
Target RTO/RPO, backup schedule, encrypted backup location, restore-test records, alternate processing strategy, contact roster, and periodic exercise results.
