# GPT-DOUG U.S. Engineering Baseline — 2026-10-07

GPT-DOUG uses an advisory-only, human-authority model for consequential decisions.
The platform may analyze and recommend; it does not autonomously execute the
recommendation.

Tracked engineering references:

- NIST Cybersecurity Framework 2.0
- NIST AI Risk Management Framework 1.0, with the 2026 revision tracked as in progress
- NIST AI 600-1 Generative AI Profile
- NIST SP 800-53 Rev. 5, SP 800-53A, and SP 800-53B
- NIST SP 800-171 Rev. 3 and SP 800-171A Rev. 3
- NIST SP 800-218 Secure Software Development Framework
- CISA Zero Trust Maturity Model 2.0
- DoD CMMC and applicable DFARS requirements
- FIPS 140-3 where validated cryptographic modules are required
- FedRAMP Rev. 5 and current 2026 FedRAMP rules when a scoped federal cloud service requires them

This list is an engineering baseline, not a certification or authorization statement.
Applicability remains dependent on the actual system boundary, data, contract, agency,
and responsible authority.

The public GPT-DOUG / Eagle Eye deployment remains a PUBLIC / TRAINING / SIMULATION
engineering environment. Regulated or restricted data requires a separately approved
boundary.

Run `gpt-doug-compliance freshness` to detect when this standards review is older
than the 30-day engineering review window.
