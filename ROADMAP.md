# GPT-Doug-LLM Roadmap

GPT-Doug is an ontology-first LLM system focused on structured knowledge, provenance, human approval, and reliable retrieval.

## Current

- Ontology-first retrieval
- Entity and relationship storage
- Proposal-based knowledge changes
- Human approval/rejection workflow
- Regression testing

## Next

### v0.2 — Knowledge Governance
- Complete proposal approval/rejection pipeline
- Provenance and confidence metadata
- Conflict detection
- Ontology revision history

### v0.3 — Knowledge Ingestion
- Corpus-to-ontology extraction
- Entity deduplication
- Relationship extraction
- Source citations

### v0.4 — Hybrid Retrieval
- Ontology-first retrieval
- Vector search fallback
- Hybrid ranking
- Multi-hop reasoning

### v0.5 — Local Models
- Ollama
- llama.cpp
- vLLM
- OpenAI-compatible providers

### v0.6 — Developer Platform
- MCP server
- OpenAI-compatible API
- Plugin/tool interface
- Evaluation suite

### v1.0
A stable, open-source ontology-first agent platform with human-governed knowledge, provenance, local model support, and measurable evaluation.
