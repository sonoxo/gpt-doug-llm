GPT-DOUG-LLM / DEFENSIVE CLIENT CONTROL

BIGO LOCAL BLOCK

Block BIGO Live's bigo.tv website and subdomains in a Chrome browser on a device you control, without sending traffic to BIGO or touching its servers.

OPEN-SOURCE RELEASE

AVAILABLE AS SOURCE

This source code is published in the public GPT-DOUG-LLM repository. Installing it is an explicit action on your own browser; visiting this page does not install or activate the extension.

VIEW EXTENSION SOURCE ↗

ACTIVATE ON YOUR MAC

  1. Download or clone the public GitHub repository.
  2. In Chrome, visit chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select tools/bigo-local-block.
  4. The local rule starts enabled. Use the extension popup to disable or re-enable it.
SCOPE AND LIMITS

This is an independent local browser block, not a global server block, cyberattack, change to BIGO's recommendation algorithm, or control over anyone else's traffic. It does not affect the iOS/Android BIGO apps or unrelated domains. No accounts, tokens, or paid APIs are required; the extension requests only Chrome's declarative network-request blocking permission.
