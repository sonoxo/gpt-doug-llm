03 / CREATE YOUR ARCHIVE

Free local crawler

The website itself cannot crawl arbitrary URLs because browsers enforce cross-origin restrictions. Run the existing XUNIA Python crawler on a domain you own or are authorized to archive, then import the JSON file here.

python3 scripts/xunia_web_mirror.py --base-url https://xunia.org/ --allow-host xunia.org --authorized --max-pages 20 --out xunia-open-web-snapshot.json

Requires Python 3.10+ and the two free scripts in the GitHub repository. Uses HTTPS only; same-host crawling, robots.txt, page count and size limits, a minimum one-second delay, and no cookies or credentials.
