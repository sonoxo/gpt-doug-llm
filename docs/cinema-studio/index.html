ONE-COMMAND MAC START

Install and run free

Paste into Terminal. A small dedicated sparse checkout is created if required; existing files are preserved. Free FFmpeg may be installed by Homebrew if missing.

curl -fsSLo "$HOME/Downloads/gpt-doug-cinema-start.sh" https://raw.githubusercontent.com/sonoxo/gpt-doug-llm/main/cinema_studio/bootstrap_mac.sh && bash "$HOME/Downloads/gpt-doug-cinema-start.sh"

Then open http://127.0.0.1:8793/ and keep the Terminal running.

Wan2.2 model weights are not included in the app. The optional model is roughly 17 GiB to download and can need much more unified memory at inference. On lower-memory Macs, the FFmpeg-based Motion Lab and Image → Video modes remain functional. No model weights will be downloaded automatically.
