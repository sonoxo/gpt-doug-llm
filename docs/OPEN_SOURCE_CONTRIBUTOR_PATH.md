# GPT-DOUG-LLM Contributor Path

This page gives new contributors a fast, bounded entry into the SONOXO / GLASS ONION ecosystem.

## Start here

Choose one lane:

- Python agent/runtime tests
- VA3LM coding workflows
- ontology and provenance tooling
- defensive intelligence parsing and validation
- documentation and examples

## First contribution checklist

1. Pick one small, reviewable improvement.
2. Keep changes scoped to the stated task.
3. Add or update tests when behavior changes.
4. Preserve provenance and human-review boundaries.
5. Do not add arbitrary remote shell, credential harvesting, scanning, fund movement, or hidden production mutation.
6. Run the repository checks before opening the pull request.

## Good starter work

- improve CLI help and examples;
- add deterministic unit tests for agent commands;
- improve ontology query documentation;
- add safe sample data for provenance validation;
- improve VA3LM beginner documentation;
- document XUNIA / ZYRA / GPT-DOUG integration points.

## Ecosystem

GPT-DOUG-LLM is one layer of XUNIA / GLASS ONION alongside ZYRA, XuniaDAO, AlmightySonoxo, and VA3LM-SAGI.

Contributor work should remain transparent, attributable, reviewable, and useful to the public codebase.
