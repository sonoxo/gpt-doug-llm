OPEN SOURCE DEPLOYMENT

Launch Instructions

01On any machine with Python 3, open the docs/tak-os directory.
02Run python3 -m http.server 8080 --bind 127.0.0.1 and open http://127.0.0.1:8080.
03Optional: on an Ubuntu VM with Docker Compose, run docker compose up -d inside that directory. Bind the service only to the VM's loopback address.
04To view from your host machine, use an authenticated SSH local port-forward to the VM rather than exposing the demo port to the public Internet.
