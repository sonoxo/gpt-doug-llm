## Exhibit

AGIBOT Link-U OS Alpha is a robotics framework that describes modular AimRT messaging, ROS2-compatible interfaces, an agent integration layer, Bazel/Docker-based development, and simulation-first reinforcement-learning tooling. Its alpha documentation focuses on Expedition A2 hardware. A separate X1 open-source family provides humanoid hardware, inference, and training references.

The accompanying GPT-Doug knowledge artifact maps the documented components to a source-cited, read-only ontology with explicit platform separation and zero physical robot control. It is a research exhibit, not a working robot, certified operating system, or affiliated AGIBOT product.
