# XUNIA Museum: Public OpenAI Model Mirror × REA

**Stage:** public model catalog, opt-in local mirror and REA static artifact inspection. No hosted proprietary models reproduced; no weights checked into GitHub.

- Official source: https://huggingface.co/openai
- Scope: all currently discoverable public ungated model repositories with approved permissive licenses
- Evidence: pinned Hub revision, file SHA-256 hashes and static REA reports
- Boundary: REA cannot recover unavailable proprietary weights; no inference or autonomous deployment
