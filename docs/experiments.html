XUNIA Sightline

COMING SOON · IN DEVELOPMENT

XUNIA Sightline is the research name for XUNIA's gaze-driven, hands-free interface work. The objective is a local-first control layer that can translate intentional gaze into accessible interface navigation while minimizing accidental activation and keeping camera-derived interaction data on the user's device whenever practical.

GAZE ESTIMATIONCamera or compatible eye-tracker input mapped into stable screen coordinates.
PERSONAL CALIBRATIONPer-user calibration, smoothing, confidence thresholds, and head-motion compensation.
INTENT CONTROLSDwell activation, deliberate actions, cooldowns, and false-positive suppression.
ACCESSIBILITY UILarge targets, visible gaze feedback, adjustable timing, contrast, and reduced-motion support.
FAIL-SAFE CONTROLImmediate pause, fallback input, confidence loss handling, and bounded system actions.
LOCAL-FIRST PRIVACYDesign target: process interaction signals locally rather than publishing raw camera feeds.
RELEASE GATE

How an experiment becomes a public demo

01 · PROTOTYPECore interaction works in a controlled development environment.
02 · VALIDATEAutomated tests and repeatable manual checks cover critical behavior.
03 · REVIEWAccessibility, privacy, safety, and failure modes are documented and reviewed.
04 · PUBLISHA public demo appears only after the preceding gates have evidence.
