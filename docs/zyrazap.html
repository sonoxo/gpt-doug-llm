zyraZap for Mac

A local Mac cleanup utility built from the real GPT-DOUG / ZYRA storage-recovery workflow: scan first, classify disposable data, preserve important large data, verify backups, and only then reclaim space.

● PROTOTYPE v0.1.0 CHROME MV3 MAC NATIVE MESSAGING DRY-RUN DEFAULT ALLOWLIST ONLY
Open source exhibit Read implementation notes Return to Museum
01 // PURPOSE

Clean “wack data” safely

Targets known developer caches and logs that can grow into tens of gigabytes without blindly deleting user documents, browser profiles, photos, credentials, or arbitrary Application Support data.

02 // CONTROL

Browser UI, bounded helper

The Chrome extension provides the dashboard. A local macOS Native Messaging helper performs filesystem inspection because Chrome extensions cannot directly manage arbitrary Mac paths.

03 // SAFETY

Fail closed

No arbitrary shell-command input. Cleanup actions are explicit allowlisted operations, with dry-run enabled by default and home-directory deletion boundaries.

04 // PROVENANCE

Born from a live recovery

The initial targets came from an actual Mac storage audit involving ZYRA SITL logs, Hugging Face caches, Claude VM bundles/caches, Cursor caches, and Codex runtime caches.

zyraZap cleanup transaction

BACKUP → VERIFY → ZAP
01 SCAN
Measure disk and allowlisted targets.
02 CLASSIFY
Separate regeneratable cache from preserve-first data.
03 BACKUP
Copy preserve-first targets to the selected external destination.
04 VERIFY
Compare source and backup before any destructive step.
05 ZAP
Remove only the selected allowlisted target.
06 REPORT
Show recovered space and operation evidence.
