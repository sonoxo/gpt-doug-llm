03 / INSTALL & TRAIN ON MAC

One-command, no-folder-conflict start

Paste the command below into Mac Terminal. It preserves the old non-Git folder and uses a verified dedicated checkout. Setup and training do not block the website from starting.

curl -fsSLo "$HOME/Downloads/gpt-doug-motion1-start.sh" https://raw.githubusercontent.com/sonoxo/gpt-doug-llm/main/open_video_model/bootstrap_mac.sh && bash "$HOME/Downloads/gpt-doug-motion1-start.sh"

The bootstrap creates or updates a separate ~/GPT-DOUG-Motion1 checkout without changing ~/gpt-doug-llm. The local server starts first; free dependencies and toy-model training run alongside it. Installation downloads PyTorch and requires available disk space. No paid services.

04 / MODEL HONESTY

What Motion-1 is—and is not

✓ Genuine open training code

Independent small diffusion architecture, prompt conditioning, local optimizer, and safe state-dict checkpoints. MIT source.

✓ Real output files

Generated GIFs and optional FFmpeg MP4s, with local metadata receipts. Procedural demo mode is labeled separately.

! No photorealistic weights bundled

Trained from scratch, initially on moving shapes. High-quality cinematic synthesis requires large training corpora and compute; the existing free Wan studio remains available separately.
