# NXYZ Cloud on GitHub Codespaces

This profile runs XUNIA Forge remotely, so the Mac only needs a browser.

1. Open the repository on GitHub.
2. Select **Code → Codespaces → Create codespace on main**.
3. Wait for the container build. The private `NXYZ Cloud Control Center` port opens automatically.
4. If it does not open, choose the **Ports** tab and open port `8787`.

The Codespace stops when inactive and consumes GitHub's included monthly compute/storage allowance. Google Drive can be connected later for exported snapshots, but it is storage rather than compute.
